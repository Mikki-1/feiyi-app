# 非遗小侠 · 非遗实训 APP 原型

非遗 × 科技 × 健康：一款面向传统非遗技艺的 AI 训练与文化传承移动端应用高保真原型。

## 在线体验
直接打开 `index.html`（单文件、零依赖、可离线运行），建议使用手机模式（420px 宽度）浏览。

## 功能模块
- 首页：全国非遗地图、籍贯解锁、身体年龄测评、AI 定制训练计划
- 课程：六大分类、在学进度、课程时间表、豆包对话式制定计划
- 练习：继续练习、3D 数字人教学、AR 摄像头姿态识别、章节进度
- 广场：积分徽章、比赛/活动报名、同好圈、打卡榜、积分兑换
- 我的：个人资料、收藏、订单、设置、登录注册

## 技术说明
纯 HTML + CSS + 原生 JavaScript，ECharts 中国地图可视化，浅色系「翠竹健康」设计语言。
